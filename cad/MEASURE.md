# 建模数据表

> 给 `cad/` 参数化模型用。单位 mm，不用换算。
> 量法：有卡尺用卡尺；没有就钢尺 + 拍照（零件旁放把尺子，镜头正对，别斜拍）。
> 精度：孔距 ±0.5、外形 ±1、高度 ±1 就够。估不准的先空着，我按常见值占位并在模型里标出来。

## 先量这 6 个（最影响结构）

| # | 量什么 | 怎么量 | 实测 |
|---|---|---|---|
| 1 | 电机轴心 → 支架安装面 | 电机装进支架后，轴中心到贴合车板那一面的距离 | |
| 2 | 支架安装孔距 + 孔径 | 两孔圆心距；孔径拿钻头比 | |
| 3 | 轮子宽度 | 卡尺夹轮子两侧 | |
| 4 | 轮子内侧面 → 支架安装面 | 决定轮距、底板要不要裁窄 | |
| 5 | 电池盒 长×宽×高 | 含外壳；要能放进 x ±38.5、y ±20 | |
| 6 | 万向轮总高 ×2 | 地面 → 安装面；圆形、方形分开量 | |
