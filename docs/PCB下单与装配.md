# 主板下单与装配

> 板子已经画完，`out/gerber/maze-car-gerber.zip` 就是可以直接上传的制造文件。
> 本文只管"怎么变成一块能用的板"。图纸背后的数据源见 `firmware/board/eda/README.md`。

## 一、这块板是什么

| 项 | 值 |
|---|---|
| 尺寸 | 91.44 × 88.90 mm（3.6 × 3.5 英寸），四角 R3.05mm 圆角 |
| 层数 | 2 层 |
| 孔 | 112 个 1.0mm（模块排针，2.54mm 栅格）+ 4 个 3.2mm（M3 安装孔，四角） |
| 走线 | 150 段，信号 12 mil、电源 20 mil；顶层 20 段（含 11 段跨线/桥接），其余在底层 |
| 阻焊 | 112 个排针孔正反两面都开了窗（比孔环大 0.05mm）——**这点最容易被漏掉，漏了就是排针焊不上** |
| 丝印 | 每个模块的中文名 + 位号，板边标题与日期 |
| 连接点 | 全部是镀通孔（via），没有贴片焊盘 —— 这是一块纯通孔的手工焊接板 |

## 二、下单（嘉立创）

1. 打开 <https://www.jlc.com> → 上传 PCB 文件 → 选 `out/gerber/maze-car-gerber.zip`
2. 系统会自己读出尺寸和层数，**核对一下是不是 91.44 × 88.90mm、2 层**
3. 参数按下表选，和券对齐：

| 参数 | 选 |
|---|---|
| 板子层数 | 2 层 |
| 尺寸 | 91.44 × 88.90 mm |
| 数量 | 5 片 |
| 板厚 | 1.6 mm |
| 铜厚 | 1 oz |
| 阻焊颜色 | 绿色（券不含彩色） |
| 字符颜色 | 白色 |
| 表面处理 | **无铅 OSP** ← 券指定的，选别的券就失效 |
| 阻焊覆盖 | 过孔开窗（我们已经在文件里画了开窗，不用勾"过孔盖油"） |
| 阻抗 | 不需要 |
| 加急 | **48 小时免费加急** |

4. 结算页手动勾选「1-6层板 OSP EDA 专用券」，价格应变成 0 元（只付运费）
5. 提交后等审单（明早开工后会走单），48 小时发货 + 快递 1–3 天

### 上传时的两个提示，都正常

- **"钻孔文件重复"**：包里 `Drill_PTH_Through.DRL` 和 `Drill_PTH_Through_Via.DRL` 内容完全一样
  （嘉立创 EDA 4.1.97 把过孔同时写进两份）。如果它报冲突，把带 `_Via` 的那份从 zip 里删掉再传。
- **"网表与原理图不一致"**：这块板的 PCB 用"裸孔 + 实铜"表示连接，没有元件焊盘，
  和原理图的符号表示天然对不上。不影响制板，忽略即可。

## 三、收货后先别插模块（5 分钟万用表检查）

板子有 116 个孔，一旦哪个孔和相邻网络短路，模块插上去就烧。按顺序做：

1. **看外观**：四角圆角是否完整、112 个孔是否都透光、孔环是否两面都有铜。
2. **测短路**（万用表蜂鸣档，任意两个网络之间应当"不响"）：
   - `VBAT` ↔ `GND`
   - `5V` ↔ `GND`
   - `3V3` ↔ `GND`
   - `5V` ↔ `3V3`（这两个是降压前后的不同电源，必须不通）
3. **测导通**（应当"响"）：
   - 电池座两孔之间（`VBAT`）
   - 任意两个 GND 孔之间（例如 BT1 的 GND 与 ESP 第 22 孔）—— 全板的 GND 现在是一整片
   - 任意两个 3V3 孔之间
4. **试插**：拿一只 2.54mm 排针/排母插几个孔，要松、要正、不要卡。

有任何一条不对，别上电，先告诉我。

## 四、焊接顺序

1. **排母**（2.54mm 单排母，按孔数剪）：先焊矮的、再焊高的。
   - U1：2 × 1×22
   - U2：2 × 1×8
   - U3：1 × 1×8
   - U4/U5/U6：各 1 × 1×6
   - J1/J2：各 1 × 1×6
   - U7/SW1/SW2：各 2 × 1×2
   - BT1：1 × 1×2
2. **别把排母焊歪**：先焊对角两个脚固定，插一只模块试一下能不能插进去，再焊剩下的。
3. **电池座**：BT1 焊 XH2.54 卧式插座（或直接焊线，注意 `+` 在哪个孔，见第五节）。
4. 全部焊完，再做一遍第三节的短路检查（这次要带着排母测）。

## 五、插模块（方向别搞反）

每行是"孔位编号:针脚名"，括号里是这个孔接的网络。

**BT1 XH**（2 孔）

**U7 M5P**（4 孔）

**U1 ESP**（44 孔）

  1:M2(AO2) / 2:VCC(3V3) / 3:C2(ENC_L_C2) / 4:C1(ENC_L_C1) / 5:GND / 6:M1(AO1)

**核对技巧**：拿万用表测某个模块的第 1 孔与它的第 2 孔，比如 ESP 的 1 孔是 3V3、2 孔也是 3V3，两个应当导通；
而 ESP 的 21 孔（5Vin/5V）与 22 孔（GND）之间必须不通。对不上就是孔位看错了，别硬插。

## 六、首次上电

1. **先只插降压模块 U7**（mini560 之类），不插 ESP、不插电机驱动。
2. 接电池 → 测 U7 的 `OUT+` 与 `OUT−` 之间是不是 5.0V 左右。
   - 没有 5V：检查 `IN+`/`IN−` 有没有接反、电池有没有电。
   - 是 12V 或别的怪值：降压模块没调好，**别插 ESP**。
3. 确认 5V 正确后，插 ESP → 测 3V3 孔对地是否 3.3V。
4. 再插 TB6612、传感器。
5. 电机（J1/J2）**最后插**，插之前先把车架空，防止一上电就窜出去。

## 七、已知的几个"不完美"，都不影响用

- **启动键 SW2 的孔距是 7.62 × 5.08 mm**（来自布线图的 3×2 格）。如果你买的是 6×6 轻触开关
  （常见 6.5 × 4.5 mm），脚会稍微差一点：掰一下脚、或者飞两根线，或者干脆不装（用板载 BOOT 键发车）。
- **电机接口 J1/J2 是 6 孔排针**，N20 电机的编码器线是 6P 端子，直接用杜邦线插，不需要焊接连接器。
- **丝印只有模块名和位号**，没有逐孔网络名。要认某个孔是什么网络，看第五节的表。
- **电机线是 12 mil（0.3mm）宽**，按 1oz 铜算约能过 1A、温升 10°C。N20 的空载电流 0.1~0.2A、
  堵转 0.6~1A，正常跑完全够；但不要让它长期堵转。
- **电池座 BT1 与降压模块 U7 之间只有 2mm 左右的空隙**，XH 卧式插座选窄一点的，或者插好之后看一眼会不会顶到。
- **没有电源指示灯、没有反接保护**：电池极性务必确认。BT1 两个孔分不清哪边是 `+` 时，
  用万用表测：与 U7 第 1 孔（`IN+`）导通的那个是 `+`，与任意 GND 孔导通的那个是 `−`。

## 八、这块板为什么长这样（给以后回看）

原始设计是一块洞洞板手焊布局（`迷宫小车主板布线.html`），35×34 格、1 格 2.54mm。
把它搬成 PCB 时保留了原来的孔位和走线，只补了三样东西：

1. GND 原本被拆成 5 块、3V3 拆成 2 块（手焊是点到点接线，不需要整片地），
   在顶层补了 5 根桥接线，让每个电源网络在板上都是一整片 —— 这样地回流才顺。
2. 加了 4 个 M3 安装孔。
3. 补了阻焊开窗（否则排针孔是盖油的）。
