# 上车固件

```
car/car.ino        主程序：按键发车、跑车循环、串口/WiFi 命令、体检命令
car/config.h       接线和要实测后修改的常数（引脚、正负号、轮径、遥测开关）
car/hw.h, hw.cpp   硬件层：TB6612、PCNT 编码器、3 × VL53L0X、MPU6050、拨码、按键、电池、灯
board/             洞洞板布线：layout.py（数据 + 自检）→ board.html（交互布线图）
car/brain.h/.cpp   大脑。整个仓库只有这一份：仿真器（../maze-sim）直接编译它
telemetry.py       电脑端遥测：实时看数据、存每次运行、从电脑发命令（只用 Python 标准库）
```

## 装环境（第一次）

1. Arduino IDE 2.x → 设置 → "附加开发板管理器网址"填 `https://espressif.github.io/arduino-esp32/package_esp32_index.json` → 开发板管理器搜 **esp32**（Espressif），装 **3.x** 版本（2.x 编译不过：`ledcAttach` 和 PCNT 驱动都是 3.x 的写法）。
2. 库管理器搜 **VL53L0X**，装作者是 **Pololu** 的那个。
3. 打开 `car/car.ino`。工具菜单：开发板选 **ESP32S3 Dev Module**，Flash Size 选 8MB。
   - 数据线插在标 **COM** 的那个口（旁边是 CH343 芯片）：USB CDC On Boot 选 Disabled。推荐用这个。
   - 插在标 **USB** 的那个口：USB CDC On Boot 选 Enabled。
4. 上传。串口监视器 115200，看到"迷宫小车就绪"就成了。什么模块都没接时它会说一串"初始化失败"，正常。

## 接线

**以交互布线图为准**：`board/board.html`（由 `board/layout.py` 生成，已发布成 artifact）。
它画了每个模块在洞洞板上的位置和全部 52 根线，分 7 步焊，能切换元件面/焊接面、逐根勾选。
改布局只改 `layout.py` 里的数据再运行一次，它会先自检：孔位冲突、模块重叠、每个网络是否连通、和 `car/config.h` 的引脚是否一致。

开发板是 VCC-GND 的 **YD-ESP32-S3**（N8R2），排针和 DevKitC-1 相同，两排间距 10 孔。下表只是速查：

| 功能 | GPIO | 接到 |
|---|---|---|
| TB6612 PWMA / AIN2 / AIN1 / STBY | 4 / 5 / 6 / 7 | 和 ESP32 同一行，直线连 |
| TB6612 BIN1 / BIN2 / PWMB | 15 / 16 / 17 | 同上。A 路 = 左电机，B 路 = 右电机 |
| I2C SCL / SDA | 42 / 41 | MPU6050 和三个测距插座 |
| XSHUT 左 / 前 / 右 | 40 / 39 / 38 | 三个测距插座 |
| 左编码器 C1 / C2 | 10 / 9 | 左电机线 |
| 右编码器 C1 / C2 | 14 / 13 | 右电机线 |
| 拨码 1 / 拨码 2 | 47 / 21 | 另一脚接 GND |
| 启动键（可选） | 2 | 另一脚接 GND；板载 BOOT 键也能用 |
| 电池电压（可选） | 1 | 电池 + → 100k → IO1 → 33k → GND |

电源：电池 → XH 插座 → Mini560 IN+ 和 TB6612 VM；Mini560 OUT+ → ESP32 **5Vin**。传感器、编码器、TB6612 的 VCC 一律接 ESP32 的 **3V3**。
ESP32 板上的 IN-OUT、USB-OTG 两处焊盘保持断开，接着电池也能插 USB 调试。

## 只有开发板时能测的（不接任何模块）

| 做什么 | 应该看到 | 说明什么 |
|---|---|---|
| 上电看串口 | `初始化失败：陀螺仪 左测距 前测距 右测距`，红灯 | 正常：这四样没接。**要是还出现"电机PWM""左编码器""右编码器"，就是代码的问题**，这三样只用芯片内部外设，不依赖外接模块 |
| `s`，按住 BOOT 再敲一次 | 按键从"松开"变成"按下"，两个拨码都是 OFF | 按键和拨码的读取 |
| `p cruise_mm_s 450` → `save` → 按 RST → `p` | 重启后还是 450；测完 `defaults` 恢复 | 参数存闪存 |
| 电脑连 WiFi `maze-car`，运行 `telemetry.py`，打 `?` | 命令列表从 WiFi 回来 | 遥测和远程命令（Mac 弹出防火墙提示时点允许） |
| `go` | `有模块没初始化成功，不能发车` | 缺模块时不会乱跑 |

## 装一个测一个

每接好一样东西，就在串口里敲对应命令，通过了再接下一样。

| 接好了 | 命令 | 应该看到 |
|---|---|---|
| 只有开发板 | `?` | 命令列表 |
| MPU6050 | `i`、`g` | 扫到 0x68；手把车逆时针转 90°，读数约 +90（是 -90 就把 `GYRO_SIGN` 改成 -1） |
| 3 颗 VL53L0X | 重新上电，`i`、`d` | 扫到 0x30 0x31 0x32；手挡在前面读数会变（镜头上的保护膜记得撕） |
| 电机 + 编码器 | `e`、`m` | 手往前滚轮子，读数为正、一圈约 +132 mm；`m` 会让每个轮子正反各转一下，**先把车架空** |
| 分压电阻、拨码、按键 | `b`、`s` | 电压和万用表量的差不到 0.1 V；拨码和按键状态对得上 |

`m` 的结果用来改 `config.h`：PWM 为正时轮子往后转，就改 `MOTOR_SIGN`；轮子往前转、编码器却是负数，就改 `ENC_SIGN`。最后它还会估一个 `vmax_mm_s`，用 `p vmax_mm_s 数值` 填进去。

## 跑车

- 灯：蓝 = 就绪，红 = 有模块没初始化成功（或电池低于 7 V），黄 = 手拿开、正在校准陀螺仪，绿 = 在跑，白 = 刚停下。
- 按启动键发车，跑的时候再按一下就急停。
- 拨码 1：OFF 稳妥档（巡航 0.38 m/s）/ ON 快档（`fast_cruise`，默认 0.55 m/s）。
- 拨码 2：OFF **比赛赛道模式**（不找岔路，第 14 个弯转完再走 35 cm 自动停车）/ ON 通用迷宫模式（左手法则，布局和图不一样时用）。
- 比赛赛道模式下，车摆在入口线外一点也没关系；通用模式下别这么摆（仿真里会把入口外的空地当成路口）。

## WiFi 遥测（调试时用，比赛时关）

1. `config.h` 里 `TELEMETRY 1`（默认）。车开机后会开一个热点：**maze-car**。仓库是公开的，默认密码谁都看得到：在 `car/` 里建一个 `secrets.h`，只写一行 `#define AP_PASS "你的密码"`（至少 8 位），它不会进仓库。
2. 电脑连上这个热点，运行 `python3 telemetry.py`。屏幕上实时显示测距、里程、状态；每次发车自动存一个 `runs/时间.csv`。
3. 在 telemetry.py 里直接打字回车就是给车发命令：`go` 发车、`x` 急停、`p` 看参数、`p cruise_mm_s 450` 改参数、`save` 存进闪存。不用插线，也不用重新烧录。
4. 车哪里犯了错，用 `python3 ../maze-sim/replay_log.py runs/那次.csv --png out.png` 在电脑上把那一次原样重放一遍，画出每一刻的测距和决策。

**比赛前**：把 `TELEMETRY` 改成 0 再烧一次，WiFi 就彻底不启动。参数先 `save` 好，重新烧录不会清掉闪存里的参数。
