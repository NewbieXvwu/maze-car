    # Agent Note: 测量模式（点两点，报万用表读数） Status: implemented ## Problem 板子焊完要逐点验证，但"这两点之间理想应该读数多少"要靠人脑记网络表：同网该响、跨电源该是容性、 跨稳压器不能量电阻。调试时最容易把容性爬升误判成短路。 ## Decision 在工具栏加「测量模式」：点两下成一对 A/B，就地算读数。网络归属由 `buildNetAt()` 从元件引脚网络 和每根线的路径点重建（跨线点跳过，两种网络在那里是绝缘的）。判读分四档：同网 0 Ω、电源对地容性、 经电源器件（Mini560 / 稳压器）电阻档无意义、其余开路；SCL/SDA 单独说明"板上没有上拉电阻，开路是正常的"。 标记画在 SVG 最上层（`drawPairs`），每对一种颜色，支持多对并排比对。 ## Consequences 只在页面里算，不改走线和网表。读数判据是理想情况：没算表笔线阻和焊锡电阻，模块插拔只影响容性大小。 ## Verification 用 node 抽出 `buildNetAt/reading` 对真实 D 数据跑过：电池±、降压输出、5V 同网、3V3 到 TB、电机 M1 到 AO1、 SCL 到 SDA、3V3 到 5V、VBAT 到 5V、地到地远端、空孔、走线中段，结论与手算网络表一致； headless Chrome 里模拟点击两次能正确生成 A/B 对并刷新面板。
