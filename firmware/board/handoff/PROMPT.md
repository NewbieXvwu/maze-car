# 任务：把这块 55×37 洞洞板的走线交叉压到 5 处以内

你是一个洞洞板（perfboard）走线优化器。元件位置已经排定、不能动；33 根导线的连接关系也已经定死、不能改。
现在这版走线有 **23 处跨线**（两根不同网络的线在同一格点垂直交叉），请重新规划走线，把跨线压得越低越好，同时总长别失控。

## 工作目录里的东西

| 文件 | 作用 |
| --- | --- |
| `problem.json` | 题目本身：板子尺寸、禁布区、每个焊点坐标、每根线的必经焊点、评分规则 |
| `candidate.json` | 当前 23 处跨线的方案，可以当基线、也可以当起点 |
| `holecheck.py` | 校验器：`python3 holecheck.py candidate.json --png check.png` |

## 你要产出什么

只产出一个文件 `candidate.json`（覆盖或另存都行），格式：

```json
{"wires": [
  {"id": 0, "path": [[23,7],[23,7.5],[21.5,7.5], ...]},
  {"id": 1, "path": [...]}
]}
```

- 33 根线，`id` 必须和 `problem.json` 里的 `wires[i].id` 一一对应，一根都不能少、不能多。
- `path` 里的点用孔位坐标（可以带 .5），**必须依次经过 `stops` 里的每一个焊点**，顺序不能改。
- 除 `candidate.json` 外不要改其它文件。

## 规则（硬性，违规就算错）

1. 坐标 `(x,y)` 是孔位，`0 ≤ x ≤ 54`、`0 ≤ y ≤ 36`。路径点必须是 0.5 的倍数，相邻两点只能水平或垂直相差 0.5（即只能走“孔与孔之间”的通道）。
2. x、y 都是整数的点是**孔**。只有本根线 `stops` 里的孔可以踩；其它整孔一律不能碰（那是别人的焊点）。
3. 不同线之间不能共用同一小段（0.5 长），也不能两条线贴在同一个格点上拐弯。同一根线自己碰自己无所谓（同网络），但别绕出明显的死圈。
4. 同一根线不要在同一格点上横穿自己（进焊点后原路返回、在焊点处掉头都可以）。
5. `hard` 里的矩形区域绝对不能进；`soft` 是模块板身，能不进就不进。
6. 每根线从 `stops[0]` 出发，按顺序经过全部 `stops`，端点和顺序都不许改。

## 评分

字典序：**先比 crossings（越少越好），再比总长（越短越好）**。目标 ≤ 5 处，总长尽量别超过 2.6 m（基线 23 处 / 2.15 m）。

## 自检（必须做，别靠心算）

```bash
python3 holecheck.py candidate.json --png check.png
```

输出里 `错误 0 条` 才算合法；`跨线 crossings` 就是你的分数（基线 23）。加 `--png` 会画一张图，方便你看走线形态。

## 几个可能有用的提示

- 33 根线里有 10 根是**总线**（一根线串好几个焊点，比如 3V3 一根串起 ESP、MPU、三个测距座）。先布总线、再布短线，通常比反过来少很多交叉。
- 板子左侧（x < 10，除了电池座和电机焊点）比较空，右下角 y > 33 也空，可以当“绕行走廊”。
- ESP 左右两排之间、以及 ESP 右排到 MPU 之间有几列空通道，横向的线优先走那里。
- 两种可行做法：
  - **(a) 增量改良**：从 `candidate.json` 出发，一根一根重布——把某根线临时删掉，在剩余走线占用的格网上给它重新找一条代价最小的路（跨线权重远大于长度权重），分数下降就保留，否则回滚。反复扫到收敛。
  - **(b) 结构重排**：先把 10 根总线沿板边和空通道排成一组大致平行的干线，再让短线从焊点垂直“搭”到最近的干线上，最后检查跨线。
- 每次改动后都跑一遍 `holecheck.py`，它会把所有违规逐条列出来（踩整孔、共用小段、没经过焊点、出界等）。
