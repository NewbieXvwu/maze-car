# 仿真器

```
sim.py                仿真器：模拟电机、打滑、激光测距（25° 视场角）、陀螺仪、编码器
replay_log.py         把真车录下的数据（firmware/telemetry.py 存的 csv）喂给大脑，原样重放
track_2026.txt        宣讲会公布的比赛赛道（180×180 cm，格距 30 cm）
maze_example.txt      手画迷宫的格式示例
```

大脑（`../firmware/car/brain.cpp`）只有一份：仿真器直接编译它，Arduino 也直接烧录它。电脑上调好的逻辑，提交之后上车就是同一份。

## 安装

```bash
pip install numpy matplotlib
xcode-select --install        # 只有 Mac 需要：装 C++ 编译器
```

第一次运行时 `sim.py` 会自动把 `../firmware/car/brain.cpp` 编译成动态库。之后改了它，下次运行会自动重新编译。

## 常用命令

```bash
python sim.py --maze track_2026.txt --race   # 跑比赛赛道，用比赛固件同样的"已知赛道模式"（最常用）
python sim.py --maze track_2026.txt    # 同一条赛道，用通用迷宫逻辑跑
python sim.py                          # 随机迷宫，左手模式，弹窗看动画
python sim.py --mode best --seed 7     # 左右手各跑一遍，挑快的那次
python sim.py --mode learn             # 先跑一遍学路线，再回放
python sim.py --maze maze_example.txt  # 跑手画的迷宫
python sim.py --batch 100              # 100 个随机迷宫，统计完赛率和用时
python sim.py --mu 0.25                # 很滑的地面
python sim.py --cell 320               # 改格子间距（毫米，默认 300）
python sim.py --png out.png            # 不弹窗，存一张轨迹图
```

比赛赛道只有一条路、没有岔路，左手和右手跑出来是同一条路线，`best`、`learn` 在它上面没有意义。随机迷宫那几条命令留着，是给"比赛当天布局和图不一样"兜底用的。

### 已知赛道模式（`BrainParams` 最后三个参数）

- `single_path = 1`：不检测侧面岔路，只在前墙处转弯；起步时前方通就直接直行（车摆在入口线外、两侧看着空也不会误转）；前墙处两侧都像有墙时先停着再看半秒，不急着掉头。
- `stop_turns = 14`、`exit_run_mm = 350`：转完第 14 个弯后再走 35 cm 停车。不加这一条，左手法则出了出口会左转两次、从入口钻回去。
- 默认三个都是"关"，仿真随机迷宫用的是通用逻辑；比赛固件按拨码 2 决定开不开。

## 仿真器模拟了什么

- 激光测距：25° 光锥（取 5 根射线中最近的），33 ms 更新一次，带噪声、偶发离谱值，超过 1.2 m 算超量程
- 电机：死区、响应延迟，左右两个电机快慢不一致
- 地面：抓地力有限，起步太猛会打滑，打滑时编码器会多算
- 陀螺仪：校准后残留的零漂和噪声
- 纸板迷宫：墙板接缝有缝（大多几毫米，偶尔一两厘米），墙板有一点歪
- 撞墙：车身任何一点碰到墙，直接判失败（比真实情况严格）
- 车一越过出口线就算完赛、停止仿真。真车要靠"已知赛道模式"数弯停车

## 仿真器没法替你做的

真实地面的摩擦力、VL53L0X 在纸板和锡箔胶带上的实际读数、电池电压下降后的车速变化。这些只能上车测，然后把测到的值填回 `BrainParams`。

## 大脑对硬件的要求（装车时要照做）

- **左右测距装在车轮轴的正上方**，离车中线 `side_y_mm`（默认 45 mm）。大脑用侧面读数什么时候变化来推算路口位置，传感器要是不在车轴上，推算就会偏。
- **前测距**在车轮轴前方 `front_x_mm`（默认 55 mm）。
- **车身尽量以车轮轴为中心**，原地转弯时才不会扫到墙。
- 实际装法和默认值不一样，改 `BrainParams` 里对应的数就行。

## 上车时怎么接

已经接好了，见 `firmware/`。大致是：每 10 ms 调用一次 `brain_step`，喂给它三个测距读数（毫米）、陀螺仪 Z 轴角速度（度/秒，逆时针为正）、左右轮累计里程（毫米），以及哪几个测距是这一轮刚更新的；再把输出的 `pwmL`、`pwmR` 交给电机驱动。发车前调用 `brain_init`。
