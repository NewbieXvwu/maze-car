# 迷宫示例。+ 是柱子，--- 是横墙，| 是竖墙，空格就是通道
# 外圈上用 S 标入口、E 标出口（写在原本该是墙的位置上）
# 每格宽 4 个字符；格子的实际尺寸用 --cell 参数设置（毫米）
# 周一拍完照，照着这个格式把真迷宫画下来，就能在电脑上跑
+---+---+---+---+---+
S       |           |
+---+   +   +---+   +
|       |   |       |
+   +---+   +   +---+
|   |       |       E
+   +   +---+---+   +
|       |           |
